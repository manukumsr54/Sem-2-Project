# Sem-2-Project
# 🎵 Spotify Clone

A simple and responsive **Spotify Clone** built as a practice project to recreate the basic look and feel of Spotify.

This project focuses on implementing a modern music-streaming interface with a sidebar, playlists, music cards, and a bottom music player.

> ⚠️ **Note:** This is a sample/educational project and is not affiliated with or endorsed by Spotify.

---

## 🚀 Features

* 🎧 Spotify-inspired user interface
* 🏠 Home page with music sections
* 🔍 Search interface
* 📚 Your Library section
* 🎵 Playlist and album cards
* ▶️ Basic music player UI
* ⏮️ Previous / Next controls
* 🔊 Volume control interface
* 📱 Responsive design
* ✨ Clean and modern layout

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactions and functionality

## 🎨 UI Sections

### 🏠 Home

Displays featured playlists, albums, and popular music.

### 📚 Library

Provides a simple interface for accessing playlists, albums, and saved songs.

### 🎵 Music Player

A bottom player containing:

* Current song information
* Play/Pause button
* Previous/Next buttons
* Progress bar
* Volume control

### 🔍 Search

A basic search interface for finding songs, artists, or playlists.

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/spotify-clone.git
```

2. Open the project folder:

```bash
cd spotify-clone
```

3. Open `index.html` in your browser.

Or use **VS Code Live Server** to run the project locally.
